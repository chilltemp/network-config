# AI Lessons

Temporary staging area for new agent corrections before they are promoted into the canonical
instruction files. Governed by
[`editing.instructions.md`](../.github/instructions/editing.instructions.md) §Self-Improvement Loop.

## How To Use This File

- Add a concise note here after a user correction or an agent mistake that is not yet reflected in
  `.github/copilot-instructions.md` or a scoped `.github/instructions/*.instructions.md` file. Tag it
  with the queue id it came from (`QN-<n>`) when there is one.
- ⛔ A repo lesson goes here, never only in an agent's private memory — other agents and the other
  Claude account cannot see memory.
- Promote durable guidance into the right instruction file during the next maintenance pass, and at
  the latest in the last phase of the plan that added it.
- Remove the note once the canonical rule exists, so this file stays short.
- **Citing a lesson:** a lesson referred to by name carries an explicit `<a id="kebab-slug">`
  immediately before its bullet, and is cited as `docs/ai-lessons.md#the-slug`.
